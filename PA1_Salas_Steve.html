Arquitectura Técnica de Físicas y Calibración del "Game Feel"

El desarrollo del Hito 1 ("El Laboratorio de Movimiento") tuvo como objetivo implementar una base sólida de física 2D que proporcione una respuesta inmediata, predecible y libre de inercia flotante artificial, aplicando los principios del diseño de Game Feel:

Componente / Mecánica Configuración en Inspector Lógica de Ingeniería y Justificación de Game Feel
Movimiento Horizontal speed = 2.0f Lectura por Input.GetAxisRaw y asignación en rb2D.linearVelocity. Elimina retardos de aceleración/frenado, dando control instantáneo al jugador.
Salto y Gravedad jumpForce = 4.0 / Grav = 1.0 Trayectoria parabólica equilibrada y proporcional a la escala y separación de las plataformas del nivel de pruebas.
Detección de Suelo OverlapCircle (r = 0.1) Chequeo físico en groundCheck con máscara de capa groundLayer. Evita rigurosamente saltos dobles o infinitos en el aire.
Barril Empujable Mass = 3.5 / Damping = 3.0 Rigidbody2D dinámico con masa mayor a la del jugador (3.5 vs 1.0) y amortiguamiento lineal para ofrecer resistencia sólida y sensación de peso real.
Bombas Destructibles Knockback Impulse = 3.0 Calcula el vector opuesto a la colisión, genera retroceso físico en el jugador y ejecuta animación de detonación en 9 fotogramas.
Monedas / UI Trigger 2D + TextMeshPro Detección instantánea por OnTriggerEnter2D, destrucción del GameObject y actualización del marcador en pantalla.

Adaptación técnica: Se implementó el encapsulamiento formal con [SerializeField], se configuró la directiva de depuración visual con OnDrawGizmosSelected() y se sincronizaron las interacciones con la nueva API linearVelocity de Unity 6 y la UI de TextMeshPro.

using UnityEngine; using TMPro; using UnityEngine.SceneManagement; /// <summary> /// Controlador principal del jugador (Misión 3 - Hito 1). /// Gestiona movimiento responsivo, salto con detección física de suelo y Game Feel. /// </summary> public class PlayerController : MonoBehaviour { [Header("--- PARÁMETROS DE MOVIMIENTO Y GAME FEEL ---")] [Tooltip("Velocidad de desplazamiento horizontal")] [SerializeField] private float speed = 2f; [Tooltip("Fuerza del impulso vertical al saltar")] [SerializeField] private float jumpForce = 4f; [Header("--- DETECCIÓN FÍSICA DE SUELO ---")] [Tooltip("Punto de referencia en los pies del personaje")] [SerializeField] private Transform groundCheck; [Tooltip("Radio del círculo de detección de suelo")] [SerializeField] private float groundRadius = 0.1f; [Tooltip("Capa que define qué objetos son suelo caminable")] [SerializeField] private LayerMask groundLayer; [Header("--- INTERFAZ DE USUARIO (UI) ---")] [Tooltip("Texto en pantalla para el contador de monedas")] [SerializeField] private TMP_Text TextCoins; // Componentes y variables de estado internas private Rigidbody2D rb2D; private Animator animator; private float move; private bool isGrounded; private int coins = 0; void Start() { rb2D = GetComponent<Rigidbody2D>(); animator = GetComponent<Animator>(); } void Update() { // 1. Lectura inmediata de teclado con GetAxisRaw (sin inercia artificial) move = Input.GetAxisRaw("Horizontal"); // 2. Aplicación directa de velocidad horizontal manteniendo la vertical (Unity 6) rb2D.linearVelocity = new Vector2(move * speed, rb2D.linearVelocity.y); // 3. Volteo de orientación del sprite según dirección de avance if (move != 0) { transform.localScale = new Vector3(Mathf.Sign(move), 1, 1); } // 4. Salto condicional a estar en el suelo (previene saltos infinitos) if (Input.GetButtonDown("Jump") && isGrounded) { rb2D.linearVelocity = new Vector2(rb2D.linearVelocity.x, jumpForce); } // 5. Sincronización de parámetros con el Animator if (animator != null) { animator.SetFloat("Speed", Mathf.Abs(move)); animator.SetFloat("VerticalVelocity", rb2D.linearVelocity.y); animator.SetBool("IsGrounded", isGrounded); } } void FixedUpdate() { // Detección física de suelo en el ciclo de física (FixedUpdate) if (groundCheck != null) { isGrounded = Physics2D.OverlapCircle(groundCheck.position, groundRadius, groundLayer); } } private void OnTriggerEnter2D(Collider2D collision) { // Recolección de Monedas (Trigger) if (collision.CompareTag("Coin")) { Destroy(collision.gameObject); coins++; if (TextCoins != null) TextCoins.text = coins.ToString(); } // Trampa mortal de pinchos: Reinicio de escena if (collision.CompareTag("Spikes")) { SceneManager.LoadScene(SceneManager.GetActiveScene().name); } // Obstáculo destructible (Bomba/Barril) con retroceso y animación if (collision.CompareTag("Barrel") || collision.CompareTag("Bomb")) { Vector2 knockbackDir = (rb2D.position - (Vector2)collision.transform.position).normalized; rb2D.linearVelocity = Vector2.zero; rb2D.AddForce(knockbackDir * 3f, ForceMode2D.Impulse); foreach (var col in collision.gameObject.GetComponents<BoxCollider2D>()) { col.enabled = false; } if (collision.TryGetComponent(out Animator obstacleAnim)) { obstacleAnim.enabled = true; } Destroy(collision.gameObject, 0.5f); } } private void OnDrawGizmosSelected() { if (groundCheck != null) { Gizmos.color = Color.green; Gizmos.DrawWireSphere(groundCheck.position, groundRadius); } } }
